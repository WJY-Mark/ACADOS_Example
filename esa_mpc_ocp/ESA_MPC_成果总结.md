# ESA MPC 横向控制求解器成果总结

## 1. 业务价值

### 1.1 问题定义

ESA/AES（紧急转向辅助/自动紧急转向）是智驾安全兜底功能，在碰撞时间（TTC）1~2 s 时触发紧急避让。该功能对横向 MPC 控制器有两个核心要求：

- **实时性**：控车频率 50 Hz，从接收车辆状态到下发控制指令的端到端延迟必须严格可控，否则直接导致控制中断。
- **控制精度**：紧急工况下轮胎工作在非线性区，控制器必须在大侧偏角下仍能精确跟踪避让轨迹。

旧优化器未充分利用 OCP 问题的结构化特性，导致：

- 求解耗时高、波动大，频繁触发下发超时，接近 **50% 的帧数据出现车辆状态跳帧**。
- 跳帧引发控制晃动，在车型少时可通过人工调参和启发式逻辑部分规避，但车型规模扩大后无法持续。
- 求解不稳定还干扰其他模块（规划、感知）的问题定位，拖慢整体功能迭代效率。

### 1.2 解决方案

基于 acados 框架重新设计横向 MPC 求解器，核心创新为**力域控制解耦轮胎非线性**——以前轮侧力变化率为控制量，使 OCP 严格保持线性 QP 结构，轮胎非线性通过求解后反向查表处理。配合变量归一化缩放、非均匀时间步长、软约束等工程设计，在保证控制精度的同时大幅提升求解效率和数值稳定性。

## 3. 过程创新

### 3.1 力域控制架构

将控制量从传统的转向角 \(\delta\) 改为前轮侧力变化率 \(\dot{F}_{yf}\)。由于力以线性形式进入牛顿第二定律，整个动力学模型严格保持线性，OCP 退化为标准 QP 问题。轮胎非线性通过求解后反向查非线性轮胎 lookup table 恢复转向角，实现**线性 QP 效率 + 非线性轮胎精度**的兼得。

### 3.2 前后轴非线性分治

- **前轴**：力域控制 + 求解后反向查表，完整保留非线性特性。
- **后轴**：基于上一控制帧规划结果的工作点线性化，逐帧更新切线斜率 \(C_r\) 和工作点 \((\bar\alpha_r, \bar{F}_{yr})\)，多帧迭代逼近真实非线性。

### 3.3 变量归一化缩放

前轮力物理量级 \(O(10^4)\) N 与角度 \(O(10^{-1})\) rad 跨度达 5 个数量级。通过缩放因子将力变量归一至 \(O(1)\)，使 QP KKT 系统条件数从 \(10^{10.5}\) 降至 \(10^{5}\)，改善 5.5 个数量级，从根本上消除数值不稳定问题。

### 3.4 非均匀时间步长

近端 0.02 s（50 Hz）保证动态响应精度，远端 0.2 s（5 Hz）覆盖 4+ 秒预测距离。相比均匀网格，在相同预测时域下将 QP 规模缩减约 5 倍。

### 3.5 结构化约束设计

- **时变侧向位移约束**：约束边界随预测时域逐步放宽，近端保证跟踪精度，远端保证可行性。
- **软约束 + L1/L2 混合惩罚**：避免极端工况下约束不可行导致求解失败。
- **SQP-RTI + HPIPM**：单次 QP 迭代即可满足实时控制要求，配合热启动进一步降低求解耗时。

## 4. 价值结果

### 4.1 实时性保障

新求解器纯求解耗时平均 **2.4 ms**（P95 < 4.5 ms），端到端总耗时平均 **4.7 ms**（P95 < 9 ms），远低于 20 ms 控制周期约束。**车辆状态跳帧率从 ~50% 降至 ~7%**，从根本上消除了因求解超时导致的控制中断和车辆晃动。

### 4.2 跨车型泛化

基于结构化 OCP 建模，车辆差异（质量、轴距、转动惯量、轮胎特性）通过运行时参数注入，无需逐车型精调权重和启发式逻辑。**新增车型适配从"人工精调数周"缩短为"参数配置即上线"**。

### 4.3 功能迭代提效

求解稳定性的提升消除了"求解晃动"这一干扰因素，使规划、感知等模块的问题定位不再受控制层面噪声干扰，整体功能调试效率显著提升。
