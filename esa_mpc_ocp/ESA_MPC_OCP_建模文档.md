# ESA MPC 横向控制最优控制问题建模文档

## 1. 背景与需求

### 1.1 需求背景

ESA/AES（紧急转向辅助/自动紧急转向）功能依赖横向 MPC 控制器实时规划避让轨迹并输出转向控制指令。旧版优化器未充分利用 OCP 问题的结构化特性，存在以下突出问题：

- **求解不稳定**：求解器频繁不收敛或超时，导致控制输出中断或跳变，车辆出现明显晃动。
- **调参成本高**：在车型较少时，尚可通过人工精细化调参、添加各种启发式逻辑来规避晃动和中断问题。但随着适配车型数量增加，各车型的质量、轴距、转动惯量、轮胎特性差异显著，逐车型精调的方式在人力和时间上均不可持续。
- **干扰问题定位**：求解不收敛引起的控制晃动与其他模块（如规划、感知）的问题耦合，严重干扰问题的根因分析，使整体功能调试效率低下。

因此，需要一个**结构化、数值稳定、可跨车型泛化**的横向 MPC 方案，从根本上解决求解可靠性问题。

### 1.2 技术难点

ESA/AES 场景对横向 MPC 提出了两个相互矛盾的极端要求：

**难点一：极致的实时性要求。**

控车频率要求 50 Hz，即必须在 **20 ms** 内完成避让轨迹规划与控制量计算。相比行车场景典型的 100~150 ms 计算时间裕度，耗时压力**提升了 5~7 倍**。任何计算超时都将直接导致控制中断。

**难点二：轮胎工作在非线性区。**

ESA/AES 在碰撞时间（TTC）约 1~2 s 时触发，车辆需要在极短时间内完成大幅度横向机动。此时前轮侧偏角远超线性区（通常 > 4°），轮胎力-侧偏角关系高度非线性。传统线性轮胎模型在这一工况下近似误差大，控制效果显著退化。

**核心矛盾：** 需要在 20 ms 的极端时间约束内，求解一个涉及轮胎非线性的最优控制问题。直接使用非线性 NLP 求解器计算量过大、无法满足实时性；而线性化后的 QP 虽然快，但轮胎线性近似在大侧偏角工况下失效。如何在**线性 QP 的计算效率**和**非线性轮胎的控制精度**之间找到兼得方案，是本工作需要解决的核心挑战。

---

## 2. 方案概述

ESA MPC 基于 [acados](https://github.com/acados/acados) 框架，采用 SQP-RTI (Real-Time Iteration) 算法求解有限时域最优控制问题（OCP），在满足转向角、侧向位移等约束的前提下，使车辆跟踪参考轨迹。

---

## 3. 核心创新：力域控制解耦轮胎非线性

### 3.1 传统方案的局限

传统横向 MPC 通常以前轮转向角 \(\delta\) 作为控制量。在此框架下，前轮侧向力与转向角的关系为：

$$F_{yf} = f_{tire}(\alpha_f), \quad \alpha_f = \delta - \beta - \frac{l_f \dot\psi}{v_x}$$

其中 \(f_{tire}(\cdot)\) 是高度非线性的轮胎力-侧偏角特性曲线。将 \(\delta\) 直接代入动力学方程后，整个 OCP 变为**非线性优化问题**，必须通过 NLP 求解器迭代求解，计算代价高、实时性差。若对轮胎力做线性化近似 \(F_{yf} \approx C_f \cdot \alpha_f\)，虽然得到了线性 QP，但在大侧偏角工况（如紧急避障）下线性近似失效，控制性能显著退化。

### 3.2 本方案：力域控制 + 反向查表

本方案的核心思想是**将控制量从转向角域转移到力域**，从而在保持 OCP 线性 QP 结构的同时，完整保留轮胎非线性特性。车辆前后轴的轮胎非线性通过不同策略分别处理：

**前轴非线性——力域控制 + 求解后反向查表：**

将前轮侧向力变化率 \(\dot{F}_{yf}\) 作为控制输入，前轮侧向力 \(F_{yf}\) 作为状态量的一部分。由于车辆横向动力学方程中 \(F_{yf}\) 本身以线性形式进入（牛顿第二定律），因此**无论前轮轮胎特性如何非线性，动力学模型始终保持线性**。求解器输出最优前轮力序列 \(F_{yf,k}^*\) 后，通过预先建立的前轮非线性轮胎 lookup table 反向查表得到前轮侧偏角，再由几何关系恢复期望转向角：

$$F_{yf}^* \;\xrightarrow{f_{tire,f}^{-1}}\; \alpha_f^* \;\xrightarrow{\text{几何关系}}\; \delta^* = \alpha_f^* + \beta + \frac{l_f \dot\psi}{v_x}$$

**后轴非线性——逐帧线性化更新：**

后轮侧向力 \(F_{yr}\) 采用工作点线性化处理。在非线性轮胎曲线 \(F_{yr} = f_{tire,r}(\alpha_r)\) 上，以工作点 \((\bar{\alpha}_r, \bar{F}_{yr})\) 做一阶 Taylor 展开：

$$F_{yr} \approx \bar{F}_{yr} + C_r \cdot (\alpha_r - \bar{\alpha}_r)$$

其中 \(C_r = \left.\frac{\partial f_{tire,r}}{\partial \alpha_r}\right|_{\bar{\alpha}_r}\) 为该工作点处的切线斜率。**线性化工作点 \((\bar{\alpha}_r, \bar{F}_{yr})\) 及斜率 \(C_r\) 来自上一控制帧的规划结果**，每帧更新，从而在多帧迭代中逐步逼近真实非线性特性。

### 3.3 方案优势

```
 ┌───────────────────────────────────────────────────────────────────────┐
 │  传统方案：δ 作为控制量                                                 │
 │  ┌───────────┐     非线性轮胎      ┌───────────┐                      │
 │  │  NLP 求解  │──── f_tire(α) ────▶│ 非线性 OCP │  计算量大，实时性差     │
 │  └───────────┘                     └───────────┘                      │
 ├───────────────────────────────────────────────────────────────────────┤
 │  本方案：Fyf 作为控制量                                                 │
 │                                                                       │
 │  前轴：力线性进入 OCP → 求解后反向查非线性表 → 恢复 δ*                     │
 │  后轴：基于上一帧结果线性化 → 工作点逐帧更新 → 逼近非线性特性               │
 │                                                                       │
 │  ┌───────────┐     力线性进入      ┌───────────┐   反向查表   ┌────┐   │
 │  │  QP 求解   │──── Fyf ────────▶│ 线性 OCP   │──────────▶│ δ* │   │
 │  └───────────┘                    └───────────┘  f⁻¹(Fyf)  └────┘   │
 │  ↑ 高效、精确                       ↑ 严格线性                         │
 └───────────────────────────────────────────────────────────────────────┘
```

1. **线性 QP 保证计算效率**：动力学模型严格线性，QP 求解在微秒级完成，满足实时控制要求。
2. **前轴完整保留非线性**：前轮轮胎非线性被移至求解器外部的查表环节，不影响 OCP 的线性结构，在大侧偏角工况下仍然精确。
3. **后轴逐帧线性化逼近**：后轮线性化工作点每帧从上一帧规划结果更新，使线性化近似在多帧迭代中持续贴近真实非线性轮胎特性。
4. **解耦设计便于工程实现**：轮胎模型更新（如路面变化、轮胎磨损）只需更新 lookup table 或线性化参数，无需修改 OCP 求解器内部结构。

## 4. 状态变量与控制输入

### 4.1 状态向量 \(x \in \mathbb{R}^5\)

| 索引 | 符号 | 物理含义 | 单位 |
|------|------|----------|------|
| 0 | \(\beta\) | 车身侧偏角 (sideslip angle) | rad |
| 1 | \(\dot{\psi}\) | 横摆角速度 (yaw rate) | rad/s |
| 2 | \(\Delta\theta\) | 航向误差 (heading error) | rad |
| 3 | \(e_y\) | 侧向位移 (lateral error) | m |
| 4 | \(F_{yf,n}\) | 归一化前轮侧向力 | — |

> **归一化**：\(F_{yf,n} = F_{yf} / S_f\)，缩放因子 \(S_f\) 使状态量保持在 \(O(1)\) 量级，改善 QP 数值条件。

### 4.2 控制输入 \(u \in \mathbb{R}^1\)

| 符号 | 物理含义 | 单位 |
|------|----------|------|
| \(\dot{F}_{yf,n}\) | 归一化前轮侧向力变化率 | — |

> **归一化**：\(\dot{F}_{yf,n} = \dot{F}_{yf} / S_d\)。

### 4.3 运行时参数 \(p \in \mathbb{R}^9\)

| 符号 | 含义 |
|------|------|
| \(v_x\) | 纵向速度 |
| \(\kappa_{ref}\) | 参考路径曲率 |
| \(C_r\) | 后轮侧偏刚度（线性化斜率） |
| \(\bar{\alpha}_r\) | 后轮侧偏角线性化工作点 |
| \(\bar{F}_{yr}\) | 后轮侧力线性化工作点 |
| \(m\) | 车辆质量 |
| \(l_f\) | 重心到前轴距离 |
| \(l_r\) | 重心到后轴距离 |
| \(I_z\) | 横摆转动惯量 |

## 5. 动力学模型

### 5.1 连续时间模型

系统动力学为线性时变 (LTV) 仿射模型：

$$\dot{x} = A_c \, x + B_{u,c} \, u + B_{d,c}$$

各矩阵定义如下：

$$A_c = \begin{bmatrix}
-\dfrac{C_r}{m v_x} & \dfrac{C_r l_r}{m v_x^2} - 1 & 0 & 0 & \dfrac{S_f}{m v_x} \\[6pt]
\dfrac{C_r l_r}{I_z} & -\dfrac{C_r l_r^2}{I_z v_x} & 0 & 0 & \dfrac{S_f l_f}{I_z} \\[6pt]
0 & 1 & 0 & 0 & 0 \\[4pt]
v_x & 0 & v_x & 0 & 0 \\[4pt]
0 & 0 & 0 & 0 & 0
\end{bmatrix}$$

$$B_{u,c} = \begin{bmatrix} 0 \\ 0 \\ 0 \\ 0 \\ S_d / S_f \end{bmatrix}, \quad
B_{d,c} = \begin{bmatrix} d_r / (m v_x) \\ -d_r l_r / I_z \\ -v_x \kappa_{ref} \\ 0 \\ 0 \end{bmatrix}$$

其中后轮干扰项：

$$d_r = C_r \cdot \bar{\alpha}_r + \bar{F}_{yr}$$

**物理直觉**：
- 第 1、2 行为侧偏角和横摆角速度的经典二自由度横向动力学，\(F_{yf}\) 以线性形式直接进入，这正是力控制方案保持线性的关键。
- 第 3 行为航向误差运动学。
- 第 4 行为侧向位移运动学。
- 第 5 行为力的积分器：\(\dot{F}_{yf,n} = (S_d / S_f) \cdot u\)，将力变化率控制量积分为力状态。

## 6. 代价函数

采用 **LINEAR_LS**（线性最小二乘）形式。

### 6.1 中间阶段代价 \(k = 0, \ldots, N-1\)

$$\ell_k(x_k, u_k) = \frac{1}{2} \| V_x \, x_k + V_u \, u_k - y_{ref,k} \|_W^2$$

其中输出映射为恒等堆叠：

$$y_k = \begin{bmatrix} I_5 \\ \mathbf{0}^\top \end{bmatrix} x_k + \begin{bmatrix} \mathbf{0} \\ 1 \end{bmatrix} u_k = \begin{bmatrix} \beta \\ \dot{\psi} \\ \Delta\theta \\ e_y \\ F_{yf,n} \\ \dot{F}_{yf,n} \end{bmatrix}$$

权重矩阵为分块对角阵：

$$W = \text{blkdiag}(Q, R) = \text{diag}\left(w_\beta,\; w_{\dot\psi},\; w_{\Delta\theta},\; w_{e_y},\; w_{F_{yf,n}},\; w_{\dot{F}_{yf,n}}\right)$$

### 6.2 终端代价 \(k = N\)

$$\ell_N(x_N) = \frac{1}{2} \| x_N - y_{ref,e} \|_{Q}^2$$

### 6.3 松弛变量惩罚

对每个软约束的松弛变量 \(s_l, s_u \geq 0\)，增加 L1 + L2 混合惩罚：

$$J_{slack}(s) = z_l^\top s_l + z_u^\top s_u + s_l^\top Z_l \, s_l + s_u^\top Z_u \, s_u$$

### 6.4 总代价

$$J = \sum_{k=0}^{N-1} \left[ \ell_k(x_k, u_k) + J_{slack,k}(s_k) \right] + \ell_N(x_N) + J_{slack,N}(s_N)$$

## 7. 约束

### 7.1 初始状态等式约束

$$x_0 = \bar{x}_0$$

### 7.2 动力学等式约束

$$x_{k+1} = A_d(p_k) \, x_k + B_{u,d}(p_k) \, u_k + B_{d,d}(p_k), \quad k = 0, \ldots, N-1$$

### 7.3 控制量硬约束

$$u_{min} \leq u_k \leq u_{max}, \quad k = 0, \ldots, N-1$$

### 7.4 前轮转向角线性路径约束（软约束）

通过割线刚度 \(C_f^{fit}\) 将前轮力映射为等效转向角，施加转向角物理限位约束：

$$\delta_{min} - s_\delta \leq C \, x_k \leq \delta_{max} + s_\delta, \quad k = 0, \ldots, N$$

其中约束矩阵：

$$C = \begin{bmatrix} 1 & \dfrac{l_f}{v_x} & 0 & 0 & -\dfrac{S_f}{C_f^{fit}} \end{bmatrix}, \quad D = \mathbf{0}_{1 \times 1}$$

该约束的物理含义为：利用小角度几何近似和割线轮胎刚度，由状态量导出等效转向角 \(\delta_{lin}\)：

$$\delta_{lin} = \beta + \frac{l_f}{v_x} \dot{\psi} - \frac{F_{yf}}{C_f^{fit}}$$

> 割线刚度 \(C_f^{fit}\) 由 Brush Tire 模型在指定侧偏角 \(\alpha_{fit}\) 处计算得到：\(C_f^{fit} = F_y(\alpha_{fit}) / \alpha_{fit}\)。

### 7.5 侧向位移软约束

$$e_y^{lb}(t_k) - s_{lat} \leq e_{y,k} \leq e_y^{ub}(t_k) + s_{lat}, \quad k = 1, \ldots, N, \quad s_{lat} \geq 0$$

上下界 \(e_y^{lb}(t), e_y^{ub}(t)\) 随预测时域逐步放宽，保证近端跟踪精度、远端可行性。

## 8. OCP 完整数学形式

$$\boxed{\min_{x_{0:N},\, u_{0:N-1},\, s} \quad \sum_{k=0}^{N-1} \left[ \frac{1}{2} \|y_k - y_{ref,k}\|_W^2 + J_{slack,k} \right] + \frac{1}{2} \|x_N - y_{ref,e}\|_Q^2 + J_{slack,N}}$$

$$\text{s.t.} \quad \begin{cases}
x_0 = \bar{x}_0 & \text{(初始状态)} \\[4pt]
x_{k+1} = A_d(p_k) \, x_k + B_{u,d}(p_k) \, u_k + B_{d,d}(p_k) & \text{(动力学)} \\[4pt]
u_{min} \leq u_k \leq u_{max} & \text{(控制硬约束)} \\[4pt]
\delta_{min} - s_{\delta} \leq C \, x_k \leq \delta_{max} + s_{\delta} & \text{(转向角软约束)} \\[4pt]
e_y^{lb}(t_k) - s_{lat} \leq e_{y,k} \leq e_y^{ub}(t_k) + s_{lat} & \text{(侧向位移约束)} \\[4pt]
s_\delta,\, s_{lat} \geq 0 & \text{(松弛非负)}
\end{cases}$$

## 9. 控制输出后处理：非线性查表恢复转向角

OCP 求解得到最优前轮力序列后，控制量的最终执行通过以下后处理环节完成：

$$F_{yf}^* = S_f \cdot F_{yf,n}^* \quad \xrightarrow{\text{反向查表}} \quad \alpha_f^* = f_{tire}^{-1}(F_{yf}^*) \quad \xrightarrow{\text{几何关系}} \quad \delta^* = \alpha_f^* + \beta + \frac{l_f \dot\psi}{v_x}$$

```
 OCP 输出             反向查表                几何恢复             执行
┌──────────┐      ┌──────────────┐       ┌──────────────┐      ┌──────┐
│ F*_yf,n  │─────▶│ α*_f = f⁻¹() │──────▶│ δ* = α*_f +  │─────▶│ EPS  │
│ (归一化力) │      │ (非线性表)    │       │   β + lf·ẏ/vx │      │转向系统│
└──────────┘      └──────────────┘       └──────────────┘      └──────┘
```

此环节在 OCP 求解器外部执行，**不影响 QP 的线性结构**，但完整利用了非线性轮胎特性。

## 10. 时间离散化

采用**非均匀时间步长**（multi-rate discretization）：

- 近端采用高频短步长（如 0.02s），保证动态响应精度。
- 远端采用低频长步长（如 0.2s），降低计算量同时覆盖足够预测距离。

```
t_0     t_1     ...   t_K            t_{K+1}       ...       t_N
|──Δt₁──|──Δt₁──|     |───── Δt₂ ──── |───── Δt₂ ───|        |
|<── 近端高频段 ──────>|<──────── 远端低频段 ───────────────────>|
```

## 11. 关键设计特点总结

1. **力域控制解耦非线性**：以 \(\dot{F}_{yf}\) 为控制量，动力学严格线性；轮胎非线性通过求解后反向查表处理，实现"**线性 QP 求解 + 非线性轮胎精度**"的兼得。

2. **归一化缩放**：\(F_{yf}\) 和 \(\dot{F}_{yf}\) 分别除以缩放因子至 \(O(1)\) 量级，改善 QP 条件数与数值稳定性。

3. **非均匀时间步长**：近端高时间分辨率保证动态响应精度，远端降低计算量同时保持足够预测距离。

4. **时变侧向位移约束**：侧向位移约束边界随预测时域逐步放宽，保证近端跟踪约束严格、远端留有可行性裕度。

5. **软约束设计**：转向角和侧向位移约束均为软约束（L1+L2 惩罚），防止极端工况下约束不可行导致求解失败。

6. **参数化模型**：后轮侧偏刚度、车辆质量等关键参数作为运行时参数注入，支持在线辨识与工况适应。
